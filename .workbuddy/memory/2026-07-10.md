## 关键设计要点
- 流式上传（requests.put + data=open(rb)），避免大文件内存占用
- 不覆盖模式下先查询远端列表跳过已存在
- 自动创建远端目录
- 失败重试（指数退避）
- 缩略图上传到 _thumbnails/ 子目录
- 旧配置自动迁移（validate_config 从 DEFAULT_CONFIG merge）

## OpenList API 方法修复

AList/OpenList 的 `/api/fs/list` 是 **POST** + JSON body，非 GET + query。
原代码用 GET 导致测试连接返回 HTTP 503。

- 新增 `_openlist_list_dir` 辅助函数（POST，解析 data.content）
- `_openlist_test_connection` 改 POST
- `_openlist_upload_file` 存在性检查改用 `_openlist_list_dir`
- `_openlist_upload_all_local` 同上
- `_openlist_ensure_remote_dir` 的 mkdir body 去掉多余 `mkdir` 字段（AList 只需 `{"path": ...}`）
